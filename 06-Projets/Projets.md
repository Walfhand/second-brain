# Projets

Créer une note ici lorsqu'une découverte doit être appliquée à un objectif concret. Indiquer le résultat attendu, les liens vers les connaissances utiles, la prochaine action et le critère de fin.

Aucun projet d'application n'est encore suivi dans ce coffre. L'[exemple C#](../80-Exemples/csharp-ci/README.md) sert de référence à adapter.
